# MarkFlow UI/UX 점검표 (Things 스타일 준수 체크리스트)

이 점검표는 `markflow-rules.md` 8장(UI·인터랙션 원칙)을 실제 개발 단계마다 점검할 수 있는 평가 항목으로 변환한 문서입니다. 모든 Phase 완료 시 이 항목을 기준으로 화면을 검토합니다.

---

## 1. 레이아웃 & 시각적 위계

- [x] **2영역 구조 유지**: 왼쪽 사이드바 + 오른쪽 본문으로만 구성되어 있는가? (상단 리본/과도한 탭 없음)
- [x] **고정 사이드바 순서**:
  - 상단: 수집함(Inbox) · 오늘(Today) · 검토 필요 · 라이브러리 · 기록(Logbook)
  - 중단: 영역(Area) > 프로젝트(Project) 2단 계층 슬롯
  - 하단: 스마트 그룹, 태그, 맨 아래 작은 엔진 상태 점 및 설정 톱니
- [x] **한 화면 = 한 가지 일**: 본문 상단에 큰 제목(26px Bold)과 짧은 설명 한 줄(15px)이 명확히 배치되었는가?
- [x] **테두리 대신 여백**: 불필요한 외곽선 대신 8px 그리드 여백과 미세한 회색조로 그룹이 구분되는가?
- [x] **강조색 절제**: 기본 중립 회색조 바탕에 오직 1개의 포인트 색상(차분한 파랑 `#2563eb`)만 사용되었는가?
- [x] **다크 모드**: 라이트 모드와 다크 모드 간의 전환이 부드럽고 가독성이 유지되는가?

---

## 2. 타이포그래피 & 시각 요소

- [x] **글꼴 규격**: 한글 Pretendard, 영문 SF Pro / Segoe UI가 정상 로드되어 선명한가?
- [x] **모서리 반경**: 카드/버튼/모달이 8~10px의 부드러운 라운딩을 유지하는가?
- [x] **약한 그림자**: 그림자가 번지지 않고 플로팅 요소(플로팅 버튼, 툴팁)에만 절제되어 적용되었는가?

---

## 3. 인터랙션 & 반응성

- [x] **엔진 상태 표시**: 사이드바 맨 아래 작은 점(초록/빨강)으로만 노출되며, 마우스 호버 시 markitdown 버전 및 상태 툴팁이 뜨는가?
- [x] **부드러운 전환 효과**: 호버 및 상태 전환 시 150~200ms 부드러운 애니메이션이 적용되었는가?
- [x] **빈 화면 (Empty State)**: 데이터가 없는 경우 막막하지 않도록 안내 문구와 깔끔한 아이콘이 제공되는가?
- [ ] **되돌리기(Undo) 우선**: 확인 팝업 대신 실행 후 토스트 및 Cmd/Ctrl+Z를 지원하는가? *(Phase 2+ 적용 예정)*
- [ ] **드래그 앤 드롭 분류**: 문서를 사이드바 프로젝트/태그로 끌어다 놓아 분류할 수 있는가? *(Phase 2+ 적용 예정)*
- [ ] **전역 빠른 입력 (Quick Entry)**: 단축키로 어디서나 작은 입력창이 호출되는가? *(Phase 8 적용 예정)*
