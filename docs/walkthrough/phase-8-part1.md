# Phase 8-(가) 완료 보고서: 그룹 체계 (영역 > 프로젝트) · 스마트 그룹 & 고급 검색 · 오늘/기록 뷰

이 문서는 DEVONthink의 핵심 장점인 **"단일 물리 파일 + 다중 논리 그룹(Replicant)"**과 **"실시간 갱신 스마트 그룹"**, 그리고 Things 3의 **"오늘(Today)"** 및 **"기록(Logbook)"** 화면을 구현한 **Phase 8-(가)** 기능의 상세 내용과 사용 가이드를 안내합니다.

---

## 1. 무엇을 만들었는가?

### ① DEVONthink 스타일 그룹 체계 (영역 > 프로젝트)
- **파일 중복 없는 다중 소속 (Replicant 원리)**:
  - 디스크 상에서는 `Library/` 폴더에 단 1개의 `.md` 파일만 존재합니다.
  - 마크다운 파일 상단 Frontmatter의 `groups: ["업무/AX 추진", "프로젝트/Argos"]` 배열에 그룹 경로를 저장하여, 한 문서가 여러 프로젝트에 동시에 소속될 수 있습니다.
- **사이드바 영역 및 프로젝트 인터랙티브 트리 (`Sidebar.tsx`)**:
  - `영역(Area)` 접기/펼치기 및 `[+ 영역 추가]` 기능.
  - 각 영역 하위에 `[+ 프로젝트 추가]` 및 삭제 기능.
- **★ 문서 드래그 앤 드롭 그룹화**:
  - 보드/목록의 문서를 사이드바의 특정 프로젝트 위로 드래그하여 놓으면:
    - 기본 드래그: 기존 그룹을 유지한 채 해당 프로젝트를 추가(DEVONthink 복제본/Replicant 모드).
    - `Alt(Option)` + 드래그: 기존 그룹을 덮어쓰고 해당 프로젝트로 이동(Move 모드).
  - 사이드바의 프로젝트를 클릭하면 해당 그룹에 속한 문서들만 보드에 필터링 표시됩니다.

### ② 고급 검색 문법 파서 (`searchQueryParser.ts`) & 스마트 그룹
- **지원하는 고급 검색 문법**:
  - 필드 검색: `tag:보고서`, `type:pdf`, `status:ready` (또는 `status:완료`), `group:AX`
  - 날짜 비교: `date:>2026-09-01`, `date:this_week` (또는 `date:이번주`), `date:today`
  - 점수 비교: `score:>=80`, `score:<70`
  - 제외어: `-임시` (해당 단어가 포함된 문서 제외)
  - 정확한 문구: `"2026 사업 계획"` (따옴표 내 구문 정확 일치)
  - 논리 연산: `보고서 OR 기획서`
  - 내보내기 여부: `exported:false` (아직 GitHub나 Obsidian으로 내보내지 않은 문서)
- **원클릭 스마트 그룹 생성**:
  - 검색창에 쿼리를 입력하면 우측에 **`[스마트 그룹 저장]`** 버튼이 나타나며, 이름을 지정하여 저장하면 사이드바 [스마트 그룹] 목록에 즉시 등록됩니다.
- **기본 탑재 스마트 그룹 3종**:
  1. `검토 필요`: 품질 점수가 70점 미만이거나 상태가 `review_needed`인 문서
  2. `이번 주 추가`: 최근 7일 이내에 변환된 최신 문서
  3. `내보내지 않음`: 아직 GitHub나 Obsidian으로 발행되지 않은 수집 문서

### ③ 오늘(Today) 뷰 (`TodayView.tsx`)
- 사이드바 **`[오늘]`** 메뉴를 클릭하면 열리는 Things 3 스타일의 깔끔한 집중 화면:
  - 🌟 **오늘 볼 문서 (Starred)**: 문서 목록에서 별표(Star)를 누른 중요 문서 상단 고정
  - 📥 **오늘 새로 들어온 문서**: 오늘 일자에 새로 변환된 문서
  - ⚠️ **품질 검토 필요 문서**: 70점 미만 또는 검토가 필요한 문서
- 오늘 확인할 문서가 모두 처리되었을 때 Things 3 스타일의 감성적인 완료 일러스트/체크마크 표시.

### ④ 기록(Logbook) 뷰 (`LogbookView.tsx`)
- 사이드바 **`[기록]`** 메뉴를 클릭하면 열리는 타임라인 화면:
  - 변환 성공, GitHub LLM-wiki 커밋, Obsidian 보관함 저장, 삭제 이력을 일자별 타임라인으로 열람.
  - 문서 총합 및 내보내기 상태 요약 대시보드 제공.

## 2. 사용자가 확인하는 방법 (단계별 가이드)

### ① 사이드바 영역/프로젝트 생성 및 드래그 앤 드롭 그룹화
1. 사이드바 **`영역`** 우측의 **`[+]`** 버튼을 클릭하고 새 영역 이름(예: `연구개발`)을 입력 후 Enter를 누릅니다.
2. 생성된 `연구개발` 영역 우측의 **`[+]`** 버튼을 눌러 프로젝트(예: `차세대 AI`)를 추가합니다.
3. **[라이브러리]** 화면에서 원하는 문서 카드를 마우스로 끌어 사이드바의 **`차세대 AI`** 프로젝트 위로 드롭합니다.
4. 해당 문서를 메모장으로 열어보면 Frontmatter에 `groups: ["연구개발/차세대 AI"]`가 안전하게 추가되어 있는 것을 확인할 수 있습니다.
5. 사이드바의 `차세대 AI` 프로젝트를 클릭하면 해당 프로젝트에 배정된 문서들만 보드에 모여 표시됩니다.

### ② 고급 검색 및 스마트 그룹 저장 테스트
1. 라이브러리 보드 상단 검색창에 `tag:보고서 score:>=80`을 입력합니다.
2. 태그가 '보고서'이고 품질 점수가 80점 이상인 문서들만 실시간으로 필터링됩니다.
3. 검색창 우측의 **`[스마트 그룹 저장]`** 버튼을 누르고 이름(예: `우수 보고서`)을 입력합니다.
4. 사이드바 [스마트 그룹] 아래에 `우수 보고서`가 즉시 생성되며, 클릭 한 번으로 언제든 해당 조건의 문서를 조회할 수 있습니다.

### ③ 오늘(Today) 뷰 및 별표(Star) 고정
1. 문서 목록에서 중요한 문서 옆의 **별표(☆)** 아이콘을 클릭하여 활성화(★)합니다.
2. 사이드바에서 **`[오늘]`** 메뉴를 클릭합니다.
3. 상단 **'오늘 볼 문서 (고정됨)'** 섹션에 방금 별표를 누른 문서가 정갈하게 표시되는 것을 확인합니다.
