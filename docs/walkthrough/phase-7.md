# Phase 7 완료 보고서: 노션형 보드 (MD 파일 기반 문서 관리)

이 문서는 MarkFlow에서 변환된 모든 마크다운 파일들을 노션 데이터베이스처럼 **목록·표·칸반·갤러리**로 관리하고, 마크다운 파일 자체를 단일 진실 공급원(Single Source of Truth)으로 삼아 동작하는 **Phase 7: 노션형 보드** 기능의 상세 구현 결과와 사용 가이드를 안내합니다.

---

## 1. 무엇을 만들었는가?

### ① File-over-Database 원칙 구현 (`documentService.ts` & `gray-matter`)
- **마크다운 파일 자체가 데이터의 주인**:
  - 모든 메타데이터(`title`, `status`, `tags`, `category`, `quality_score`, `groups`, `exported`, 사용자 정의 필드)는 `Library/` 내의 `.md` 파일 상단 YAML Frontmatter에 보관됩니다.
  - 앱을 삭제하거나 SQLite DB 파일이 유실되더라도 `Library/` 폴더만 있으면 언제든지 `[색인 다시 만들기]` 버튼으로 100% 동일하게 복원할 수 있습니다.
- **무손실 라운드트립 (Lossless Round-trip)**:
  - 한글 유니코드, 특수문자(`!@#$%^&*()`), 따옴표, 줄바꿈, 중첩 배열이 포함된 문서를 읽고 쓸 때 본문과 기존 커스텀 필드가 1바이트의 왜곡 없이 보존됩니다.

### ② 4종 노션형 보드 뷰 (Things 3 미니멀 스타일)
사이드바의 **[라이브러리]** 화면 우측 상단에 정갈한 세그먼트 전환 버튼(`[목록] [표] [칸반] [갤러리]`)이 배치되어 원클릭으로 보기를 전환할 수 있습니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│ 라이브러리 보드                     [ 목록 ] [ 표 ] [ 칸반 ] [ 갤러리 ] │
├────────────────────────────────────────────────────────────────────────┤
│ [ 🔍 한국어/영문 FTS5 검색... ]  [상태: 전체] [분류: 전체] [최신순 ▾]  │
└────────────────────────────────────────────────────────────────────────┘
```

1. **목록 보기 (`BoardListView.tsx`, 기본)**:
   - Things 3 스타일의 깔끔한 가로 행 레이아웃.
   - 상태 불릿 점(초록: 완료, 파랑: 수집함, 주황: 검토 필요, 회색: 보관됨), 제목, 카테고리 칩, 태그, 변환 일시, 품질 점수 배지 표시.
2. **표 보기 (`BoardTableView.tsx`)**:
   - Notion 데이터베이스 스타일의 인터랙티브 테이블.
   - 상태 셀 클릭 시 드롭다운이 열려 인라인으로 상태 변경 가능.
   - 카테고리 셀 클릭 시 인라인 텍스트 입력창으로 변환되어 즉시 수정 가능.
3. **칸반 보기 (`BoardKanbanView.tsx`)**:
   - 상태 기준 4개 열 제공: `수집함 (Inbox)` | `검토 필요 (Review)` | `완료 (Ready)` | `보관됨 (Archived)`.
   - **★ 카드 드래그 앤 드롭 즉시 Frontmatter 갱신**:
     - 카드를 마우스로 끌어 다른 열로 놓으면, 백그라운드에서 실제 디스크의 `.md` 파일 상단 `status: ready`가 즉각 갱신됩니다.
4. **갤러리 보기 (`BoardGalleryView.tsx`)**:
   - 본문에 포함된 첫 번째 이미지(`assets/<slug>/...`)를 썸네일로 추출하여 상단에 렌더링.
   - 이미지가 없는 문서는 소스 파일 형식(`pdf`, `docx`, `pptx` 등)에 맞춘 세련된 아이콘 커버 카드로 표시.

### ③ SQLite FTS5 한국어 트라이그램(Trigram) 전문 검색
- 형태소 분석기 설치 없이도 한국어(자모/음절 단위 부분 일치) 및 영문/숫자를 초고속으로 검색할 수 있는 `conversions_fts` 가상 테이블 구현.
- 상단 검색창에 단어를 입력하면 제목뿐만 아니라 **마크다운 본문 전체**, 태그, 카테고리를 실시간으로 검색하여 일치하는 문서를 즉시 필터링합니다.

### ④ 외부 편집기 양방향 동기화 감시자 (`libraryWatcher.ts`)
- MarkFlow 외부(예: VS Code, Obsidian, Typora, 메모장 등)에서 `Library/` 폴더 안의 `.md` 파일을 수정하거나 새로 추가, 삭제하면 `LibraryWatcher`가 이를 감지하여 SQLite 색인과 보드 화면을 자동으로 새로고침합니다.

### ⑤ 문서 관리 핵심 기능
- **새 빈 마크다운 생성 (`+ 새 문서`)**:
  - 제목, 카테고리, 태그를 입력하면 표준 Frontmatter가 작성된 새 `.md` 파일이 즉시 생성되고 상세 편집기로 연결됩니다.
- **문서 복제 (`문서 복제`)**:
  - 기존 마크다운 및 참조하는 첨부 이미지 에셋 디렉터리까지 완벽하게 복제하여 `(사본)` 문서 생성.
- **문서 보관 / 보관 해제 (`보관`)**:
  - `status: archived`로 마킹하여 기본 목록에서는 숨기고, `보관 문서 포함` 필터 체크 시 조회 가능.
- **다중 선택 플로팅 일괄 작업 바**:
  - 문서들을 체크박스로 다중 선택하면 화면 하단에 플로팅 바가 슬라이드 업되어 일괄 상태 변경, GitHub/Obsidian 일괄 내보내기, 일괄 삭제 수행.
- **색인 다시 만들기 (`[색인 다시 만들기]` 버튼)**:
  - `Library/` 디렉터리 내 모든 `.md` 파일을 전수 재스캔하여 SQLite DB와 FTS5 검색 색인을 100% 재구축.

## 2. 사용자가 확인하는 방법 (단계별 가이드)

### ① 라이브러리 보드 열기 및 4종 뷰 전환
1. 왼쪽 사이드바에서 **`[라이브러리]`** 항목을 클릭합니다.
2. 우측 상단 세그먼트 버튼에서 **`[목록]`**, **`[표]`**, **`[칸반]`**, **`[갤러리]`**를 차례로 클릭하여 다양한 시각화 레이아웃을 확인합니다.

### ② 칸반 드래그 앤 드롭과 마크다운 Frontmatter 갱신 검증
1. 보기 모드를 **`[칸반]`**으로 전환합니다.
2. `수집함` 열에 있는 문서 카드를 마우스로 드래그하여 **`완료`** 열로 이동시킵니다.
3. 카드가 즉시 `완료` 열로 이동합니다.
4. 파일 탐색기에서 `내 문서\MarkFlow\Library\<문서명>.md` 파일을 메모장이나 VS Code로 열어봅니다.
   - 상단 YAML Frontmatter의 `status: ready` (또는 완료)로 바뀌어 있는 것을 확인할 수 있습니다.

### ③ 표(Table) 인라인 셀 편집
1. 보기 모드를 **`[표]`**로 전환합니다.
2. 특정 문서의 **`상태`** 셀을 클릭하고 드롭다운에서 `검토 필요`를 선택하면 즉시 색상 배지가 바뀌며 파일에 반영됩니다.
3. **`카테고리`** 셀을 클릭하여 `기획서` 또는 `보고서`를 입력하고 Enter를 누르면 카테고리가 즉시 저장됩니다.

### ④ 갤러리 썸네일 확인
1. 이미지가 포함된 문서를 변환한 후 보기 모드를 **`[갤러리]`**로 전환합니다.
2. 문서 카드 상단에 본문의 첫 번째 이미지가 선명한 썸네일로 표시되는 것을 확인합니다.

### ⑤ 새 문서 작성 및 외부 편집 동기화
1. 상단 **`[+ 새 문서]`** 버튼을 클릭하고 제목 `2026 AX 추진 계획`을 입력하여 문서를 생성합니다.
2. 파일 탐색기에서 `Library/2026-ax-추진-계획.md` 파일을 외부 편집기로 열어 본문에 새로운 내용을 적고 저장합니다.
3. MarkFlow 라이브러리 보드로 돌아오면 외부에서 수정한 내용이 자동으로 반영되어 있는 것을 확인합니다.
