# MarkFlow 품질 점수(Quality Score) 산식 및 평가 기준

MarkFlow는 변환된 마크다운 문서가 원본의 의도와 내용을 얼마나 완전하고 정확하게 담아냈는지 측정하기 위해 **0~100점 척도의 종합 품질 점수**를 자동으로 부여합니다.

---

## 1. 품질 평가 4대 핵심 축

```
┌─────────────────────────────────────────────────────────────┐
│                   MarkFlow 종합 품질 점수 (100점)            │
├───────────────┬───────────────┬───────────────┬─────────────┤
│ 문서 완성도    │ 구조 보존도   │ 이미지 처리율 │ 텍스트 순도 │
│   (40점)      │   (30점)      │   (20점)      │   (10점)    │
└───────────────┴───────────────┴───────────────┴─────────────┘
```

### ① 문서 완성도 (Completeness, 최대 40점)
- **추출 텍스트의 유효 분량**: 원본 문서에 담긴 내용이 비어 있거나 누락되지 않고 온전히 텍스트로 추출되었는지 검사합니다.
- **빈 문서 / 불완전 추출 감점**:
  - 0바이트 또는 텍스트 미추출 시: `0점` 처리
  - 스캔 PDF 등 텍스트가 거의 없는 페이지: OCR이 활성화되지 않아 내용이 누락되면 패널티 감점 부여

### ② 구조 보존도 (Structure, 최대 30점)
- **제목 계층 구조(Heading Hierarchy)**: `#`, `##`, `###` 등 문서의 단락 및 제목 계층이 체계적으로 구성되어 있는지 검사합니다.
- **표(Table) 정합성**: 표 데이터 변환 시 열 개수가 일치하고 누락된 구분선이 없는지 검사합니다.
- **목록(List) 구문**: 번호 매기기나 글머리표가 마크다운 표준 구문으로 잘 유지되었는지 확인합니다.

### ③ 이미지 및 시각 자료 처리율 (Asset Handling, 최대 20점)
- **내장 이미지 보존**: DOCX, PPTX, PDF 등에 포함된 핵심 다이어그램 및 이미지가 소실되지 않고 `Library/assets/<slug>/` 폴더에 고화질로 저장되었는지 측정합니다.
- **상대경로 링크**: 마크다운 본문에서 해당 이미지를 깨짐 없이 연결하고 있는지 확인합니다.
- *(내장 이미지가 원래 없는 순수 텍스트/표 문서는 기본 20점 만점 부여)*

### ④ 텍스트 순도 (Purity, 최대 10점)
- **깨진 유니코드 문자 감지**: 인코딩 오류로 인한 특수 대체 문자(``, `\ufffd`) 감지 시 건당 감점.
- **비정상 줄바꿈 및 잡음 제거**: 문맥에 맞지 않는 줄바꿈, 페이지 번호 부스러기(`Page 1 of 10`)가 깔끔하게 정리되었는지 평가합니다.

---

## 2. 점수별 등급 및 화면 표시

| 종합 점수 | 등급 및 배지 | UI 표시 색상 | 상태(Status) | 설명 |
|---|---|---|---|---|
| **85점 이상** | **우수 (Good)** | 초록색 (Green) | `inbox` | 거의 완벽하게 변환되어 즉시 지식 베이스로 사용 가능 |
| **70점 ~ 84점** | **양호 (Fair)** | 파란색 (Blue) | `inbox` | 본문과 구조가 잘 보존되었으며 경미한 서식 차이만 있음 |
| **70점 미만** | **검토 필요 (Review Needed)** | 노란색/주황색 (Amber) | `review_needed` | 스캔 문서 글자 누락, 이미지 깨짐 등이 있어 사용자의 확인 권장 |

---

## 3. 사이드바 및 필터 연동

- 점수가 **70점 미만**인 문서는 자동으로 `status: review_needed`로 분류됩니다.
- 왼쪽 사이드바의 **[⚠ 검토 필요]** 메뉴 옆에 해당 문서 수가 실시간 배지로 표시되어 사용자가 즉시 확인하고 프로필을 "최고 품질"로 변경해 재변환할 수 있습니다.
